给 agent 用的日历

能让 Claude Code 帮你排日程的日历

更新于 2026-11-22

逐日（ASMO）是免费开源的 Mac 日历和待办，编程 agent 可以直接用。第一次打开时，它会装好 asmo 命令，给 Claude Code 和 Codex 装上技能，并在 Claude 桌面版里注册 MCP。之后 agent 就能读你的日程，添加、挪动、勾掉待办，还能给某一天写笔记。agent 的每一次改动都能撤回，数据只在你的 Mac 和你自己的 iCloud 里。

逐日通过 MCP 接 Google 日历只用 Apple 日历
接入 Claude Code第一次打开自动装好命令、技能和 MCP官方远程服务，或者自己建 Google Cloud 项目接社区版没有自己的命令行或 MCP

agent 能帮你做什么

  • 聊着天就排好了。跟 Claude Code 说"今晚 9 点到 10 点跑步，明天下午 3 点和李总通电话"，两件事就进了日历。
  • 写当天的笔记。agent 写的是 Markdown：标题、清单、表格、图片、流程图，在应用里直接显示。
  • 不靠猜。日期和时间是以字段传进来的，不从一段话里猜；返回的是 JSON。
  • 随时撤回。asmo undo 能撤回 agent 最近的改动，再往前一步也行。

怎么到你的手机上

有时间的待办进 Apple 日历，没时间的进提醒事项，都在一个叫"逐日"的日历和列表里。在 iPhone 上打个勾，Mac 上也就完成了。逐日没有自己的服务器，同步走的是你自己的 iCloud。

怎么开始

  1. 下载逐日，打开一次。它会把 asmo 装到 ~/.local/bin，给 Claude Code 和 Codex 装好技能，并在 Claude 桌面版里注册 MCP。
  2. 问你的 agent："我这周有什么安排？"或者"按这张清单帮我排明天。"
  3. 也可以自己用命令：asmo add "跑步" --day today --time 21:00 --end 22:00。

常见问题

Claude Code 能管理我的日历吗？

能。装好逐日之后，Claude Code 通过 asmo 命令和技能读写你的日程；Claude 桌面版通过逐日的 MCP。

Codex 也能用吗？

能。逐日给 Codex 装了同样的技能，任何能运行命令行的 agent 都能用 asmo。

逐日里有 AI 模型吗？

没有。应用本身不运行任何模型，思考交给你已经在用的 agent，逐日只按它说的记下来。

数据会上传吗？

不会。数据是你 Mac 上的一个本地文件，只有你自己的 iCloud 日历和提醒事项会同步到其他设备。

免费试试逐日

需要 Apple 芯片的 Mac 和 macOS 15 或更高版本。不用注册，没有服务器，不用订阅。
