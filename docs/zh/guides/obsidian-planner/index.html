Obsidian 用户的日程方案

更新于 2026-11-22

如果你的笔记在 Obsidian，日程却记在别的地方，逐日能把两者放进一个 Mac 应用。它的笔记就是一个 Markdown 文件夹，所以 Obsidian 的库直接能用：表格、提示框、公式、流程图、Excalidraw 手绘都在原处显示。每天的安排就放在旁边，待办自动进 Apple 日历和提醒事项，再到你的 iPhone 上。免费，开源。

从 Obsidian 带过来的

  • 还是那些文件。笔记就是文件夹里的 Markdown，打开你的库，Obsidian 照样用同一批文件。
  • 块都能显示。表格、提示框、行内和块公式、mermaid 流程图，都在原处画出来。
  • Excalidraw。手绘的保存方式和 Obsidian 的 Excalidraw 插件一样，同一个文件两边都能打开。
  • Git 同步。如果库是一个 Git 仓库，逐日会自动提交、拉取、推送，手机上的 Obsidian 也能看到。

怎么开始

  1. 下载逐日并打开。
  2. 把逐日的笔记文件夹选成你的 Obsidian 库。
  3. 在当天的页面写下计划，待办会出现在日历和提醒事项里。

常见问题

逐日能打开我的 Obsidian 库吗？

能。笔记就是 Markdown 文件夹，把逐日指向你的库，两个应用用的是同一批文件。

要放弃 Obsidian 吗？

不用。很多人继续用 Obsidian 写东西，用逐日管同一个库里的日程和待办。

怎么同步到 iPhone？

日程通过你自己 iCloud 上的 Apple 日历和提醒事项同步；放在 Git 仓库里的笔记通过 Git 同步。
