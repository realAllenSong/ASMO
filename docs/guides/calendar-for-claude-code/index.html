Calendar for coding agents

A calendar Claude Code and Codex can use

Updated 2026-11-22

ASMO is a free, open-source calendar and to-do list for the Mac that coding agents can use directly. It installs an asmo command and a skill for Claude Code and Codex, plus an MCP server for the Claude desktop app, so an agent can read your days, add and move items, check things off and write a day's notes. Every change can be undone, and your data stays on your Mac and in your own iCloud.

What an agent can do with it

  • Plan from a conversation. Tell Claude Code "I'm running from 9 to 10 tonight and have a call with Li at 3 tomorrow", and both land in the calendar as you talk.
  • Write the day's page. Agents write Markdown: headings, checklists, tables, pictures and mermaid diagrams, drawn in the app.
  • Work with structured data. Dates and times arrive as fields, so nothing is guessed from free text. Answers come back as JSON.
  • Stay reversible. asmo undo takes back the last change an agent made, and the one before it.

How it reaches your phone

Items with a time become events in Apple Calendar and the rest become reminders, in a calendar and a list named 逐日. Check something off on your iPhone and it is done on your Mac. ASMO has no server of its own; syncing goes through your iCloud.

Getting started

  1. Download ASMO and open it once. It puts asmo in ~/.local/bin, gives Claude Code and Codex the skill, and registers its MCP server with the Claude desktop app.
  2. Ask your agent: "What's on my calendar this week?" or "Plan tomorrow from this list."
  3. Or use the command yourself: asmo add "Run" --day today --time 21:00 --end 22:00.

FAQ

Can Claude Code manage my calendar?

Yes. With ASMO installed, Claude Code uses the asmo command and its skill to read and change your days; the Claude desktop app uses ASMO's MCP server.

Does it work with Codex?

Yes. ASMO installs the same skill for Codex, and any agent that can run a shell command can use the asmo command.

Does ASMO run an AI model?

No. The app runs no model of its own; the agent you already use does the thinking, and ASMO stores exactly what it is told.

Is my data uploaded anywhere?

No. Your data is a local file on your Mac. Only your own iCloud Calendar and Reminders sync to your other devices.
